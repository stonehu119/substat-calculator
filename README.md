# Substat calculator for Honkai: Star Rail

### Deployed at [hsr-sub-counter.vercel.app](https://hsr-sub-counter.vercel.app/)

Built using React + Vite + Tailwind and Typescript

## Adding data
All the character/lightcone/relic data is added in `src/data/json`. Should be pretty self explanatory from there.<br>
There's also a GitHub Actions workflow that tries to auto update the site and creates a PR if you feel like using it.
